# Log Parser Microservice

Микросервис для парсинга, агрегации и хранения логов устройств.

## Функциональность

- Прием файлов логов через REST API
- Парсинг логов с извлечением информации об узлах, портах и характеристиках
- Построение топологии сети
- Хранение данных в PostgreSQL
- REST API для доступа к данным

## Требования

- Docker и Docker Compose
- Go 1.22+ (для локальной разработки)
